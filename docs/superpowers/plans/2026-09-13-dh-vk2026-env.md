### Task 3:26.2 依赖库 classpath 组装

**Files:**
- Create: `mc-src/scripts/fetch-libraries.py`
- Generate: `mc-src/artifacts/libs/*.jar`(~60-90 个,gitignore)、`mc-src/artifacts/classpath.txt`(入库)

**Interfaces:**
- Consumes: Task 2 的 `mc-src/artifacts/26.2.json`。
- Produces: `mc-src/artifacts/classpath.txt`(每行一个 jar 绝对路径)——Task 4 Vineflower 的 classpath 输入。

- [ ] **Step 1: 写 fetch-libraries.py**

```python
#!/usr/bin/env python3
"""下载 MC 26.2 全部平台无关依赖库 jar 到 mc-src/artifacts/libs/,
生成 mc-src/artifacts/classpath.txt(每行一个绝对路径,供 Vineflower classpath)。"""
import hashlib
import json
import os
import sys
import urllib.request

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))  # mc-src/
ART = os.path.join(ROOT, 'artifacts')
LIBS = os.path.join(ART, 'libs')
os.makedirs(LIBS, exist_ok=True)

meta = json.load(open(os.path.join(ART, '26.2.json')))
cp, skipped = [], 0
for lib in meta.get('libraries', []):
    art = lib.get('downloads', {}).get('artifact')
    if art is None or art.get('url') is None:
        skipped += 1  # native 分类器 / 仅 rules 的库
        continue
    name = art['url'].rsplit('/', 1)[-1]
    dest = os.path.join(LIBS, name)
    if not os.path.exists(dest):
        req = urllib.request.Request(art['url'], headers={'User-Agent': 'dh-vk2026-decompile'})
        data = urllib.request.urlopen(req, timeout=180).read()
        open(dest, 'wb').write(data)
        if art.get('sha1'):
            actual = hashlib.sha1(data).hexdigest()
            if actual != art['sha1']:
                sys.exit(f'sha1 mismatch: {name} expected {art["sha1"]} got {actual}')
    cp.append(dest)

cp = sorted(set(cp))
open(os.path.join(ART, 'classpath.txt'), 'w').write('\n'.join(cp) + '\n')
print(f'ok: {len(cp)} jars in classpath, skipped {skipped} (natives/rules-only)')
```

```bash
head -5 mc-src/artifacts/classpath.txt
```
Expected: ok 行输出 jar 数(预期 60-90);classpath.txt 行数与之相等;抽查的每行路径都真实存在。若某库 404/超时:脚本重跑会续传(已下载的跳过)。

- [ ] **Step 1: 写 decompile.sh**

```bash
#!/usr/bin/env bash
# MC 26.2 一键可复现重反混淆(Vineflower 1.12.0 + 官方 mojmap)
# 用法: ./mc-src/scripts/decompile.sh
set -euo pipefail

HERE="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
ROOT="$(cd "$HERE/.." && pwd)"                 # mc-src/
ART="$ROOT/artifacts"
CLIENT_JAR="$ART/client.jar"
SERVER_JAR="$ART/server.jar"
VF="$ART/vineflower-1.12.0.jar"
MAPFILE="$ROOT/mappings/mappings.txt"
CPFILE="$ART/classpath.txt"

# --- 输入校验 ---
[ -f "$CLIENT_JAR" ] || { echo 'client.jar missing'; exit 1; }
[ -f "$SERVER_JAR" ] || { echo 'server.jar missing'; exit 1; }
[ -f "$VF" ] || { echo 'vineflower jar missing'; exit 1; }
[ -f "$MAPFILE" ] || { echo "mapping missing: $MAPFILE"; exit 1; }
[ -f "$CPFILE" ] || { echo 'classpath.txt missing'; exit 1; }
echo "2dc72797acbc1b63fc16a11c4ac393605f453754  $CLIENT_JAR" | sha1sum -c -
echo "823e2250d24b3ddac457a60c92a6a941943fcd6a  $SERVER_JAR" | sha1sum -c -
# Vineflower sha256:执行 Task 2 Step 3 后,把 CHECKSUMS.txt 里的值填进下面引号
echo "_____________FILL_FROM_CHECKSUMS_____________  $VF" | sha256sum -c -

# --- 反混淆 client(全量:common+client+vk)---
rm -rf "$ROOT/client"
java -Xmx24g -jar "$VF" "$CLIENT_JAR" "$ROOT/client" "$CPFILE" 25 "$MAPFILE" 1

# --- 反混淆 server(临时目录)---
rm -rf "$ROOT/.server-tmp" "$ROOT/server"
java -Xmx24g -jar "$VF" "$SERVER_JAR" "$ROOT/.server-tmp" "$CPFILE" 25 "$MAPFILE" 1

# --- 去重:server 树只保留 client 树没有的类(common 以 client 为权威)---
python3 - "$ROOT/client" "$ROOT/.server-tmp" "$ROOT/server" <<'PYEOF'
import os, shutil, sys
client_root, server_tmp, server_out = sys.argv[1:4]
keep = set()
for dirpath, _, files in os.walk(client_root):
    for f in files:
        if f.endswith('.java'):
            keep.add(os.path.relpath(os.path.join(dirpath, f), client_root))
n = 0
for dirpath, _, files in os.walk(server_tmp):
    for f in files:
        if not f.endswith('.java'):
            continue
        p = os.path.join(dirpath, f)
        rel = os.path.relpath(p, server_tmp)
        if rel in keep:
            os.remove(p)
        else:
            n += 1
            dest = os.path.join(server_out, rel)
            os.makedirs(os.path.dirname(dest), exist_ok=True)
            shutil.move(p, dest)
print(f'server-exclusive .java files: {n}')
PYEOF
rm -rf "$ROOT/.server-tmp"
echo 'decompile done'
```
把 Task 2 Step 3 得到的 Vineflower sha256 填入脚本中 FILL_FROM_CHECKSUMS 占位行。

**Interfaces:**

- Produces: vk 包清单报告;混淆残留结论;Task 7 探针 mixin 的目标类从这里定位。

- [ ] **Step 1: 写 verify-vk.sh**

```bash
#!/usr/bin/env bash
# vk 渲染器完整性自检:vulkan 相关包目录、每目录 .java 计数、总数、抽样 3 文件
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
OUT="$ROOT/verify-vk-report.txt"
{
  echo "# vk 完整性验证报告 $(date -Is)"
  echo
  echo '## vulkan 相关包目录'
  find "$ROOT/client" -type d \( -iname '*vulkan*' -o -iname '*vk*' \) | sed "s|$ROOT/||" | sort
  echo
  echo '## 每目录 .java 计数'
  find "$ROOT/client" -type d \( -iname '*vulkan*' -o -iname '*vk*' \) -print0 |
    while IFS= read -r -d '' d; do
      printf '%6d  %s\n' "$(find "$d" -maxdepth 1 -name '*.java' | wc -l)" "${d#"$ROOT"/}"
    done | sort
  echo
  echo '## vk 相关 .java 总数(含子目录)'
  find "$ROOT/client" \( -ipath '*vulkan*' -o -ipath '*/vk/*' \) -name '*.java' | wc -l
  echo
  echo '## 抽样:前 3 个 vk .java 文件各取前 30 行'
  find "$ROOT/client" \( -ipath '*vulkan*' -o -ipath '*/vk/*' \) -name '*.java' | sort | head -3 |
    while read -r f; do
```

```java
package dev.dhvk;

/**
 * 26.2 官方渲染器实际在用的 Vulkan 原生句柄持有者。
 *
 * <p>架构原则(spec §7-3):mod 侧只依赖 native 句柄(LWJGL 地址),
 * 不引用 Mojang 内部包装类,防小版本更新重构包装类导致 mod 全线报红。
 */
public final class VkHandles {

    public static long device = 0L;
    public static long queue = 0L;
    public static long commandPool = 0L;
    public static boolean captured = false;

    private VkHandles() {
    }

    public static void capture(long deviceHandle, long queueHandle, long commandPoolHandle) {
        device = deviceHandle;
        queue = queueHandle;
        commandPool = commandPoolHandle;
        captured = true;
    }

    public static String format() {
        if (!captured) {
            return "not captured yet (probe mixin not fired)";
        }
        return String.format("device=0x%x queue=0x%x pool=0x%x", device, queue, commandPool);
    }
}
```

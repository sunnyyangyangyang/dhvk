## 本轮排障沉淀(26.2 新渲染器对 mod 的三道墙)
1. **mixin 0.8.7**: @Inject 无 args=@Capture → 用 @Redirect; @Inject handler 必须带
   CallbackInfo 收尾(即使 void 目标); 构造器 HEAD 注入必须 static handler。
2. **资源管线**: 26.2 vanilla pack 纯文件系统根(client jar + --assetsDir), classpath 资源
   要走 developmentConfig 钩子(loom 1.17.20 / loader 0.19.5 / DLI 全链无人设); 且
   MultiPackResourceManager 按 exposeNamespace 定死的命名空间集合预建管理器表 →
   mod 着色器要既推根(pushClasspathResources)又 exposeNamespace。
3. **关闭路径**: 自有 GpuBuffer 必须在 RenderSystem.shutdownRenderer(DEVICE.close 之前)
   释放, 否则 VVL 对象追踪在 vkDestroyDevice 报 VUID-vkDestroyDevice-device-05137。

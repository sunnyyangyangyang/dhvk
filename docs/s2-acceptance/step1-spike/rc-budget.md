## R-c 定死

- **全局最坏 = 45366 quads（高山/洞口复合区，run60）** → 272197 顶点。
- **R-c = 全局最坏 × 1.5**（计划 Task 1 门规则）：
  - VBO 预算 = 272197 × 16B × 1.5 ≈ **6.53 MB**
  - IBO 预算 = (6 + 45366×6) × 4B × 1.5 ≈ **1.56 MB**
  - 单帧合计 ≈ **8.1 MB**
- **32MiB 硬上限联立**（笔记 §10.2/§10.3：RTX 5090 maxResourceHeapSize = 32MiB）：
  几何池 = 32MiB − 描述符表 262144B − 驱动预留 96768B ≈ **31.6MiB**；
  R-c 形 3 帧保留窗驻留 ≈ 3 × 8.1MB + 0.36MB ≈ **24.7MB < 31.6MiB（裕量 22%）**。
  → 单带形态下堆预算不咬紧，**堆 init 常数无需增长**（现 360448B = 表+预留）；
  实测最坏形（无 ×1.5）驻留 ≈ 16.6MB（裕量 47%）。
- **10km 多带（Task 7）仍为联合标定对象**：多 L0 带并行驻留时按 §10.2-3 与
  bandFar/fogStart/L0 带边缘三参数联立重裁，本预算只定死单带 R-c 常数。
